Gestione File System

Hardware e File System

Esplora l'architettura logica delle partizioni Linux, il funzionamento del mount dei dischi rigidi e la gerarchia standard delle directory di Ubuntu.

Argomenti principali trattati

I moduli didattici approfondiscono i seguenti temi legati all'archiviazione dati:

  • Gerarchia standard: la logica dietro la ramificazione del filesystem partendo dalla radice /.
  • Cartelle di sistema: studio dettagliato di /etc (configurazioni), /var (dati volatili) e /usr (programmi).
  • Montaggio dischi (Mount): come Linux mappa i dispositivi hardware fisici ed esterni (es. chiavette USB) tramite il comando mount.
  • Diagnostica memoria: utilizzo dei comandi di misurazione spazio disco df, du e del gestore dischi lsblk.
