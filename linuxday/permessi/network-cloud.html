Sicurezza e Servizi Cloud

Introduzione teorico-pratica alle reti informatiche in Ubuntu, alla gestione della sicurezza con firewall ed all'integrazione di servizi cloud e backup automatici.

Argomenti principali trattati

I moduli didattici approfondiscono i seguenti temi legati alla rete ed alla sicurezza cloud:

  • Fondamenti di rete: indirizzamento IP statico e dinamico, configurazione DNS e subnetting di base.
  • Firewalling con UFW: configurazione guidata del firewall predefinito di Ubuntu (Uncomplicated Firewall) per proteggere le porte aperte.
  • Cloud e Storage remoto: differenze tra Public, Private e Hybrid Cloud, e le modalità di interazione sicura tra server locali ed istanze cloud.
  • Strategie di Backup: implementazione di backup crittografati regolari per garantire la sicurezza del dato contro incidenti e intrusioni.
